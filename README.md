# Software FJ - Práctica Simulada Fase 4

Aplicación desarrollada en Python con interfaz gráfica (Tkinter) para el curso de Programación de la UNAD. Implementa Programación Orientada a Objetos (POO), clases abstractas, polimorfismo, manejo avanzado de excepciones y registro de eventos en archivo de logs (`sistema.log`) sin utilizar bases de datos.

** Requisitos **
- Tener instalado  la versión de Python 3 en el equipo.

** Cómo ejecutar el proyecto **
1. Clona o descarga este repositorio en tu computadora.
2. Abre una terminal o consola en la carpeta del proyecto.
3. Ejecuta el script principal con el comando:

```bash
python ANEXO_3_FASE_4.py```
